# Getting help

| You want to                     | Go to                                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| Learn how to integrate Whisk    | [docs.usewhisk.xyz](https://docs.usewhisk.xyz)                                               |
| Ask a question or share an idea | [Discussions on usewhisk/whisk](https://github.com/usewhisk/whisk/discussions)               |
| Report a bug                    | An issue on the affected repository, using the bug form                                      |
| Report a security problem       | [Private vulnerability reporting](https://github.com/usewhisk/whisk/security/advisories/new) |
| Recover a stuck transfer        | The receipt link from the widget. If it fails, open a bug with the source transaction hash   |
