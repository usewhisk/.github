# Code of conduct

Whisk adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and assume good intent.
- Critique code and ideas, never people.
- No harassment, discrimination, sexualised language or imagery, doxxing, or
  personal attacks, in any Whisk space.
- No spam, token shilling or scam links.

## Scope

All Whisk repositories, issues, pull requests, discussions and community channels, and
anyone representing Whisk in public.

## Enforcement

Report a problem privately through
[private reporting on usewhisk/.github](https://github.com/usewhisk/.github/security/advisories/new).
Only the maintainer, [@Signor1](https://github.com/Signor1), sees it, and reports are
handled confidentially.

Responses follow the Covenant's enforcement guidelines: correction, warning, temporary
ban and permanent ban, depending on severity.
