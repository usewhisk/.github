# Whisk

Stablecoin payments infrastructure. Accept USDC from any chain, settled where you want
it, with Arc as the home chain.

Whisk moves USDC between a payer's wallet and a merchant's wallet using Circle's
Cross-Chain Transfer Protocol. It never holds funds.
